# Configuration Evidence

This folder contains evidence of the configuration and verification of the Thuso Legal Aid Centre network implemented in Cisco Packet Tracer.

## Router Configuration Evidence

Evidence includes the configuration and verification of the router subinterfaces used for inter-VLAN routing.

Relevant verification includes:

- `show ip interface brief`
- `show running-config`

The router was configured with 802.1Q subinterfaces for VLANs 10, 20, 30, 40, 50 and 60.

## Switch Configuration Evidence

Evidence is provided for the configured switches.

Relevant verification includes:

- `show vlan brief`
- `show interfaces trunk`

These commands were used to verify VLAN creation, access-port assignments and trunk operation.

## End-Device Configuration Evidence

Screenshots are provided for selected PCs and servers to demonstrate:

- IPv4 addressing
- Subnet masks
- Default gateways
- DNS configuration

## Server Configuration Evidence

Evidence is included for the DHCP/DNS Server and Web Server.

The evidence demonstrates the configured network services used by the client network.

## Topology Evidence

A screenshot of the completed Packet Tracer topology is included to show the overall physical and logical arrangement of the network.

## Purpose of the Evidence

The configuration evidence supports the implementation documented in the project and provides verification that the configured network corresponds with the planned VLAN, VLSM, routing and service design.
